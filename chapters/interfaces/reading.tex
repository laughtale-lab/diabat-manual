\section{Reading states from different calculations}\label{sec-reading}
For states obtained from a single quantum chemistry calculation, use the single-package input in \script{chap-interfaces}{script-statepack-single}. To combine states obtained from separate external calculations, follow the multiple-package structure in \script{chap-interfaces}{script-statepack-multiple}. A common example is multiple-excitation FPHD using a separately calculated neutral reference state for a charged system.

When electronic states are combined from different calculations, the program must be able to express their density matrices in compatible orbital and AO representations. Different geometries, atom orders, or AO basis sets can make that comparison invalid. Preserve the same nuclear geometry, atom ordering, and AO basis for a cross-calculation reference and target states. The number of electrons is permitted to differ for the multiple-excitation FPHD reference described in Section~\ref{sec-fphd}. This does not relax the geometry or basis requirements. Other tasks can impose different restrictions, which are explained in their respective sections.

Absolute paths and paths relative to the working directory are both supported. If a data file contains results from several quantum chemical methods, use the optional \keyref{key-statepack-method}{method} keyword to select the intended data. Otherwise the first recognized method in the file is used automatically.
